Operation
Deploy a clean committed source via server/deploy/ship.sh. It retains database,
source and prior image backups. Then make a fresh custom-format pg_dump,
capture preexisting business-row hashes, dry-run inside the running API image,
and apply the import once. Verify batch/file/row counts, existing row hashes,
all imported saved-view/print paths, image revision and public HTTPS health.
Private evidence is retained outside the repository under the operator's
pantong-data-import-20261009 directory and private host backup directory.
Do not restore a full backup over newer user writes without reconciliation.
